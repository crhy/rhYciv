# Project notes

Working notes, decisions and standing orders for this project, kept by Claude Code while working with rhY. Each file is one fact or decision; `[[name]]` links point to other notes (some live in other crhy repos' `docs/notes/`).

- [rhyciv-advanced-settings-optin](rhyciv-advanced-settings-optin.md): On rhYciv, new rules beyond plain Civ II play and any developer tooling go behind Advanced Settings toggles that default to off.
- [rhyciv-decomp-comparison](rhyciv-decomp-comparison.md): rhY cancelled the decompilation comparison for rhYciv; rules are to be learned black-box from the real Civ II install and rhY's saves instead
- [rhyciv-defork-identity](rhyciv-defork-identity.md): rhYciv must carry no upstream Civ2-clone/axx0 identity — names, namespaces, folders, and data paths should all read as rhYciv.
- [rhyciv-fix-what-you-find](rhyciv-fix-what-you-find.md): On rhYciv, rhY wants incidental defects found along the way fixed, not reverted as out of scope.
- [rhyciv-generated-art-direction](rhyciv-generated-art-direction.md): rhY wants procedurally generated rhYciv tile art to look hand-made and physically plausible, not ruler-straight or merely layered.
- [rhyciv-playability-first](rhyciv-playability-first.md): On rhYciv, playability and responsiveness outrank every other kind of work, and are fixed before new features or polish.
- [rhyciv-release-gate](rhyciv-release-gate.md): rhYciv releases are tested by rhY as a locally built flatpak before anything is pushed.
